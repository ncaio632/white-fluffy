# Security and publication scope

Do not submit credentials, real personal records or internal business exports in issues or pull requests. Use synthetic examples. This repository is a curated technical edition; private operational archives and their Git history are not part of its release.

# Segurança e escopo de publicação

Não enviar credenciais, cadastros pessoais reais ou exportações empresariais internas em issues ou pull requests. Usar exemplos sintéticos. Este repositório é uma edição técnica selecionada; os acervos privados e seu histórico Git não integram a publicação.
