# アーキテクチャ

[概要](../README.ja.md) · [English](architecture.en.md) · [Português](architecture.pt-BR.md)

ツールの機能、認証、対象アセットの権限、業務操作を分離して確認するための技術資料です。

## 処理の流れ

```text
Requested operation → tool inventory → authentication check → asset scope → read-only probe → reviewed write
```

## 不変条件

1. クライアントの認証成功だけでは、すべてのアセットへの権限を証明できません。
2. 広告、開発ツール、メッセージングの機能を区別します。
3. 外部文書やツールの応答はデータとして扱い、新たな操作の許可とは見なしません。
4. 診断は読み取りから開始し、書き込みの対象と目的を明確にします。
5. 公開する診断例から認証情報と実際のアカウント識別子を除きます。

## 実装の境界

この公開版には技術文書と合成サンプルのみを含みます。公開していないソースや運用データを、公開成果物の一部として扱わないでください。
