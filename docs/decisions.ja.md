# 設計判断の記録

[概要](../README.ja.md) · [判断と影響・English](decisions.en.md) · [Português](decisions.pt-BR.md)

## 背景

ツールの機能、認証、対象アセットの権限、業務操作を分離して確認するための技術資料です。

## 判断の要点

クライアントの認証成功だけでは、すべてのアセットへの権限を証明できません。

## 影響

境界を明示することで、入力条件と責任範囲を確認しやすくします。その一方で、状態、例外、変更履歴を個別に管理する必要があります。具体的な判断とトレードオフはリンク先の英語版およびポルトガル語版に記載しています。
