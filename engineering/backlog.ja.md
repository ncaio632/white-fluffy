# 実装バックログと受入条件

**計画の要約。詳細は[英語版](backlog.en.md)。完了済みとは主張しない。**

| 項目 | 成果物と受入条件 |
|---|---|
| WF-B1 | パーサーと正規化。重複キーを拒否し、同じ内容のキー順変更で同じハッシュを得る。 |
| WF-B2 | 一覧・認証観測。不完全、古い、別セッションの証拠を拒否し秘密を記録しない。 |
| WF-B3 | 対象権限評価。認証成功でも拒否・不明なら送信数ゼロ。各一致項目を個別検査する。 |
| WF-B4 | 効果表と承認台帳。不明効果、期限切れ、不一致、再利用を拒否する。 |
| WF-B5 | 送信と照合。効果発生後のタイムアウトを不確定とし、再起動でも再送しない。 |
| WF-B6 | 診断とアダプター適格性。秘密カナリアを除去し、各ツールの境界を試験する。 |

B1から順に依存する。実環境の試行前に信頼できる時計、証拠期限、承認者確認、永続監査を定める。書込み試行前に承認拒否ケースを実測し、照合用読取りを用意する。照合できなければ書込みを無効のままにする。

四つの役割は能力、認可、操作、証拠をレビューする。自ら起動せず、アカウント操作を許可しない。正規化方式の変更は契約版を更新し待機中承認を無効化する。公開報告は測定済みケースだけを含め、私的資料で不足を補わない。
