# Synthetic fixtures / Exemplos sintéticos / 合成例

English: Every file here is synthetic documentation input. See [validation cases](../../contracts/validation-cases.json) for schema expectations and [validation guide](../../engineering/validation.en.md) for semantic errors. Files named `invalid-` may intentionally pass schema validation; they exercise a separate semantic boundary. No fixture proves a real operation occurred. Dates use an artificial clock and do not describe current service state.

Português: Os arquivos são exemplos sintéticos. Consulte a matriz para distinguir falha estrutural e rejeição semântica. Um exemplo válido no esquema não autoriza uma operação real.

日本語: すべて合成データである。構造検査と意味検査の期待結果を区別する。スキーマに適合しても実際の操作権限や実行結果を証明しない。
